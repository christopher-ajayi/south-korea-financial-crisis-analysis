
# The 1997-1998 South Korean Financial Crisis

### A Time-Series Analysis

## Overview

This project examines the impact and economic dynamics of the 1997-1998 Asian financial crisis in South Korea through time-series analysis of selected macroeconomic and financial indicators.

The analysis explores how key indicators evolved over **before**, **during**, and **after** the study period, with particular attention to the conditions surrounding the financial crisis.

## Analysis

The project uses historical time-series data to examine trends in:

* Economic activity
* Consumption
* Investment
* Exchange rates
* Interest rates
* Current account
* Government budget position etc.

The analysis and visualizations were conducted using **Gretl**.

## Tools & Methods
